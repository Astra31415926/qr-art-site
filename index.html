Напиши один файл index.html, который позволяет: Создавать QR-код из текста (используй библиотеку qrcodejs). Читать QR-код из загруженного файла (используй библиотеку jsQR). Требования к коду: Современный темный дизайн. Поле ввода текста и кнопка «Создать». Кнопка «Выбрать файл» для сканирования. Чистый JavaScript, библиотеки подключи через CDN. Весь код (HTML, CSS, JS) должен быть в одном файле.
